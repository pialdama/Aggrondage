Chaque point est le score publié dans l'hypothèse principale d'un sondage (1er tour) ; les listes de candidats testées varient d'un sondage à l'autre, un candidat non testé n'a pas de point à cette date. Les courbes épaisses sont des tendances LOESS (régression locale pondérée) calculées sur les sondages où le candidat est testé — ajustez la fenêtre pour plus ou moins de lissage. Jusqu'en juin 2026, les instituts testaient Jordan Bardella comme candidat du RN ; Marine Le Pen l'a remplacé dans les hypothèses à partir de juillet.

Un sondage n'est pas une prédiction : il photographie une opinion à un instant donné, avec une marge d'erreur de ± 1 à 3 points selon la taille de l'échantillon. Les résultats doivent être interprétés avec prudence, surtout plus d'un an avant le scrutin (1er tour : 18 avril 2027).
